# ASCII Ocean · DSH 背景动画插件

原作者：https://github.com/stackedlol/ascii-sharks

v0.1.0
把 ascii-sharks 动画做成 DSH 会话中栏的活体背景：

v0.2.0
添加了右下角的控制面板

v0.3.0
添加了鲤鱼和金鱼
添加了鼠标点击特效 点击水面会出现波纹 点击鱼身上鱼会受到惊吓

v0.4.0
修复了问题：
1.控制面板不显示数值
2.两个不透明度滑杆的步进不一致
3.浅色主题下首屏背景过暗，文字几乎看不清
4.控制面板点击水里的生物→鲨鱼（原版）→新建会话 新建对话背景仍然是金鱼和鲤鱼
v0.5.0
新增锤头鲨（cephalofoil 一字形头翼、眼睛长在头翼两端）和魔鬼鱼（蝠鲼：菱形翼展、鞭状尾、翼尖随呼吸起伏）。
控制面板“水里的生物”新增：鲨鱼 + 锤头鲨 + 魔鬼鱼（默认）、全是锤头鲨、全是魔鬼鱼；新增“魔鬼鱼颜色”。

v0.6.0
锤头鲨改为直接移植 ascii-sharks 原项目：细颈 + 独立绘制的头翼（span/sweep/depth，眼睛在头翼两端），不再靠加宽半宽曲线近似。
移除魔鬼鱼（蝠鲼）及其配色项；旧的 manta 设置会自动回落到鲨鱼。
默认阵容：鲨鱼 + 锤头鲨。

v0.6.1
点击交互加强：点击鲨鱼任意部位（锤头鲨含头翼，判定 0.17L / 0.21L）会受惊，0.2 秒内提速约 3 倍冲出去，约 1.3 秒后回到巡游速度；
点击处仍会荡开波纹，鱼群照旧被惊散。

v0.6.2
点击水花：每次点击都会在落点炸开一簇水滴（10–16 颗，受击时 ×1.7），带重力抛物线和淡出，落点先闪一帧 `*` 冲击冠，
再叠上原有的两圈涟漪。颜色随深浅主题切换（深色冷白、浅色深蓝）。

v0.6.3
点击水花再加两道：落点先炸出向上的一股水柱（`|` 叠成、顶端 `!`，约 0.42 秒涨落），
受惊逃跑的鲨鱼会从尾部持续甩出水花，在身后拖出一条尾迹（每 0.055 秒一簇，持续到惊吓结束）。
所有水效（水滴、冲击冠、水柱、涟漪）统一改成蓝色：深色主题 #76B2FF 系，浅色主题 #2A68D0 系。

v0.6.4
水效改用独立的 FX 图层：会话里海洋本身只有 10% 不透明度，点击特效会被一起压暗，所以另建一张同尺寸、
不随海洋淡出的 canvas 专画水花，始终 100% 不透明度；颜色也换成更实的蓝。

v0.6.5
水花半径收小：水滴改成“竖直抛出 + 少量横向漂移”，回落到水面即消失（不再拖着往下跌），
横向最远约 55px（原来 280px）；涟漪圈半径 34–86px（原来 46–124px）。
