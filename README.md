# ASCII Ocean · DSH 背景动画插件

原作者：https://github.com/stackedlol/ascii-sharks

v0.1.0
把 ascii-sharks 动画做成 DSH 会话中栏的活体背景：

v0.2.0
添加了右下角的控制面板

v0.3.0
添加了鲤鱼和金鱼
添加了鼠标点击特效 点击水面会出现波纹 点击鱼身上鱼会受到惊吓

v0.4.0
修复了问题：
1.控制面板不显示数值
2.两个不透明度滑杆的步进不一致
3.浅色主题下首屏背景过暗，文字几乎看不清
4.控制面板点击水里的生物→鲨鱼（原版）→新建会话 新建对话背景仍然是金鱼和鲤鱼

v0.5.0（本地适配 DSH 0.2.2）
1.改用官方 `conversation.hero.frame` 图层插槽，不再挂在会话级 `conversation.input.dock` 上：切换/新建会话、首页进入对话时画布不再被销毁重建（之前每次重建都会从透明淡入，表现为闪烁）
2.画布改为相对会话主体的 absolute 定位，去掉每帧同步位置的 fixed 画布和往 React 节点里硬插 DOM
3.首页/会话状态直接读取插槽的 `hero` 属性，不再靠 CSS 类名猜测
4.尺寸没变时不再重置画布（重置 canvas.width 会清空画面）
5.侧栏等嵌入式会话里不再渲染

v0.5.1（修复打字/选模型时整栏闪烁）
动画的画布、引擎和齿轮面板改为插件模块自己持有，按会话主体元素缓存复用；React 每次按键重绘输入框导致的图层重建会在 400ms 内被复用抵消，不再重置淡入。画布被 React 从 DOM 里摘掉时会自动放回。图层本身不再在 JSX 里渲染 canvas。
